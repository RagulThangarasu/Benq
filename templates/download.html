Download BenQ PDFs & HTML

Crawls every folder under the five shipped guide sections and downloads the latest generated PDF for each product into benq_pdfs/<PRODUCT>/, based on AEM’s last-modified time. Defaults to English; choose another language or all available languages below.

Run download

Products and AEM credentials are configured in download_benq_pdfs.py. The download runs server-side; you can leave this page open while it works.

Run HTML download

Crawls every product folder under the shipped guide categories (zowie, business, consumer, infty, education) and downloads the rendered page for every topic under each product's en folder, into benq_html/<PRODUCT>/<topic>.html (the landing page becomes index.html). Set BENQ_AEM_HTML_LANGS to a comma list or * for other languages, and BENQ_AEM_GUIDE_CATEGORIES to change which categories are crawled. Existing files are overwritten with the newest version.

The guide root and AEM credentials are configured in download_benq_html.py. The crawl runs server-side; you can leave this page open while it works.
